# 面板模型

> 语言：中文  
> 最后更新：2026-10-13  
> 切换：[英文版](../../en/panel/README.md)

当同一批企业、个人或地区在多个时期被重复观测时，可以使用面板模型。先明确研究问题依赖哪种信息：同一个体自身的变化、不同个体之间的差异，还是随时期变化的横截面关系。`statgpu.panel` 提供六类估计器，分别处理这些不同目标。

## 按研究问题选择模型

如果长期存在的个体差异可能与解释变量相关，先考虑[固定效应](panel-ols.md)或[一阶差分](first-difference-ols.md)。希望同时利用个体内和个体间变异时，[随机效应](random-effects.md)需要满足下表中更强的正交条件。

如果希望把所有个体、所有时期的原始记录放在一起，用同一个截距和同一组斜率描述解释变量与结果的关系，可考虑[合并 OLS](pooled-ols.md)。它不会消除企业等个体长期存在的差异；如果这些未纳入模型的差异（例如管理水平）与解释变量有关，合并回归的斜率就可能混入它们的影响。仅提供个体标签或改用稳健标准误，都不能消除这个问题。

研究个体长期均值之间的差异时，使用 [BetweenOLS](between-ols.md)；研究各时期横截面系数的平均值时，使用 [FamaMacBeth](fama-macbeth.md)。这些估计目标不能相互替代，改变协方差选项也无法补救识别假设不成立的问题。

| 估计量 | 统计视角 | 主要识别来源 / 额外条件 |
|---|---|---|
| [PanelOLS](panel-ols.md) | 个体效应和/或时间效应被视为固定但未知的干扰参数。 | 使用去除所选固定效应后剩余的变异；不要求固定效应与解释变量的历史路径正交。 |
| [FirstDifferenceOLS](first-difference-ols.md) | 从含固定个体效应的模型出发，通过差分消除不随时间变化的个体效应。 | 使用同一个体在相邻已观测时期之间的变化。 |
| [RandomEffects](random-effects.md) | 个体效应被建模为随机成分。 | 经典随机效应解释要求随机效应与解释变量历史正交，例如 $E(a_i\mid X_i)=0$。 |
| [BetweenOLS](between-ols.md) | 在个体内对 $X$ 和 $y$ 取均值，使每个个体对应一条均值观测。 | 使用个体之间的变异；若要恢复基础面板模型中相同的结构斜率，需要均值后的复合误差与均值后的解释变量正交。 |
| [PooledOLS](pooled-ols.md) | 所有堆叠观测共享同一个条件均值关系。 | 使用全部堆叠变异；合并回归误差必须对解释变量外生。 |
| [FamaMacBeth](fama-macbeth.md) | 每个时期分别进行一次横截面回归。 | 对各时期的斜率估计取平均，并根据这些斜率的时间序列变异进行推断。 |

## 准备逐行对齐的面板数据

采用长表：每行是一条个体—时期观测，`X` 的形状为 `(n_observations, n_features)`，`y` 的形状为 `(n_observations,)`。筛选或排序时，个体标签、时间标签和聚类标签必须随同一行数据一起移动。标签用来描述面板结构，除非明确放入 `X`，否则不是解释变量列。

- `PanelOLS`：为启用的固定效应提供 `entity_ids` 和/或 `time_ids`；默认不启用任何固定效应。
- `RandomEffects`、`BetweenOLS`、`FirstDifferenceOLS`：提供 `entity_ids`。一阶差分还应提供能反映真实顺序的 `time_ids`，除非输入已按所需的个体内顺序排列；差分连接相邻已观测时期，不会补齐缺失时期。
- `FamaMacBeth`：提供 `time_ids`；每个保留时期的横截面设计都必须满列秩，包括截距列。
- `PooledOLS`：拟合时可以不提供个体标签，但计算面板拟合统计量和 LM 诊断时需要它们。

不要给所有模型统一添加截距列。数组接口中，`PooledOLS`、`BetweenOLS` 和 `FamaMacBeth` 会自动加截距；`PanelOLS` 和 `RandomEffects` 使用传入的列，一阶差分不估计水平截距。各模型页分别说明公式接口，并提供可独立运行的 CPU 示例。

## 完成拟合，再解释结果

进入所选模型页，先运行其中可独立执行的 CPU 示例，再按需查完整参数表。示例自行生成面板数据，并说明系数顺序、观测数和自由度；结果部分继续解释标准误和该模型中预测值的含义。

确认系数推断可用后，将 `coef_` 与 `bse_`、`conf_int_` 一起阅读。较小的 p 值不能证明外生性成立。[拟合统计量](fit-statistics.md)帮助区分个体内、个体间和总体拟合；[模型诊断](diagnostics.md)用于回答具体的模型比较问题，不是一套自动选型流程。

面对重复观测，应根据预期的误差相关结构选择标准误。[协方差指南](covariance.md)说明 HC、聚类和时间相关协方差各自处理什么问题，以及哪些模型支持这些选项。`FamaMacBeth` 则使用各时期系数的时间序列。稳健标准误既不改变识别假设，也不会将经典模型 F 自动改成稳健 Wald 检验。
