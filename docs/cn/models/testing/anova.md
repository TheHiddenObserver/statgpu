## ANOVA 回答什么问题？

方差分析（ANOVA）研究数值型响应的均值如何随分组或因素水平组合变化。
输入包括响应观测及其分组或析因设计；分析将与模型有关的变异和模型无法解释的变异区分开，
在所选方法的假设下，用 F 统计量和 P 值检验关于均值或因素效应的指定假设。

例如，比较几种处理下的测量结果时，即使各组总体均值相同，样本均值也往往不同。
ANOVA 判断这些差异相对于背景变异是否足够明显。处理组只是一个应用；分组也可以来自
观测到的类别，能否作因果解释则取决于研究设计。

对于有 $k$ 个水平的单因素设计，总体检验的原假设为

$$H_0: \mu_1=\mu_2=\cdots=\mu_k.$$

在模型假设成立时，较小的 P 值支持“各组总体均值并非全部相等”这一结论。
至于具体哪两组不同、差异有多大、是否存在因果关系，还需要进一步分析。
反过来，未拒绝原假设也不能证明均值相等：样本过少或测量噪声较大时，
有实际意义的差异也可能难以检出。要判断两组是否等效，需要另行设定问题并选择分析方法。

## 先分清因素、分组与实验单位

**因素**是用来区分条件或类别的变量，其取值称为**水平**。例如，肥料种类有三个水平，
每株植物只使用其中一种，那么接受同一种肥料的植物就组成单因素设计中的一个组。
只有当处理在植物层面分配、观测也在这个层面独立时，才能把每株植物作为实验单位。
同一株植物上测量的多片叶子，不能直接当作多个独立的处理重复。

如果再增加“浇水方案”这个有两个水平的因素，让每种肥料都搭配每种浇水方案，
就得到六个**单元格**，分别对应六种因素组合。平衡双因素设计要求每个单元格有相同数量的
独立观测，仅仅让某个因素各水平的总样本量相同还不够。如果同一批植物在不同浇水方案下
被反复测量，就需要重复测量模型或其他能处理相关数据的方法。

双因素分析包含不同问题：肥料的主效应考察对浇水方案取平均后的差异，浇水的主效应
则考察对肥料种类取平均后的差异。**交互作用**表示一个因素对应的差异会随另一个因素的
水平而变化。有交互作用时，平均主效应可能掩盖方向相反的变化，或只出现在某个条件下的
明显差异。[平衡双因素教程](anova-twoway.md)将说明这些效应各自的原假设和检验方法。
因此，析因分析并不是分别做几次互不相关的单因素检验。

<a id="variance-intuition"></a>

## 为什么比较方差能判断均值差异？

在每个组内，观测值会围绕本组均值波动；不同组的样本均值也会不同，其中既可能有
抽样噪声，也可能有总体均值真正不同带来的差异。经典单因素模型把总的离差平方和分成
**组间变异**和**组内变异**。平方和除以相应的自由度，得到均方，用来衡量变异大小，
同时考虑估计它时还剩多少份独立信息。

在总体均值相等、总体方差相同的经典原假设下，组间均方和组内均方估计的是同一个误差方差。
用前者除以后者就得到 F 统计量；组间均方明显更大时，就有证据反对原假设。
P 值表示：如果原假设模型成立，得到至少这么大的 F 统计量的概率。
它不是“原假设为真”的概率。

这是**经典方差分解**的直觉，并不是适用于所有 ANOVA 的统一公式。在平衡析因模型中，
每个效应各有自己的平方和与自由度，需要与相应的残差均方比较。Welch ANOVA 则根据
各组均值的估计精度加权，并调整统计量及参考分布的自由度，以考虑方差不等的情况。
[经典单因素](anova-oneway.md)、[Welch](anova-welch.md)和[双因素](anova-twoway.md)
页面分别给出对应的模型与公式。

<a id="assumptions"></a>

## 核对设计与误差假设

- **独立性取决于数据收集方式。** 先确认抽样或随机分配以什么为单位，以及观测是否
  来自同一个受试者、家庭、批次或其他可能导致相关性的来源。把相关观测当作独立重复，
  即使样本很多也会影响推断；通过分布检查也不能证明独立性。
- **正态性针对组内或单元格内的误差。** 经典检验的精确 F 参考分布要求误差正态且具有
  相同方差。即使各组满足假设，均值不同也可能使混合后的直方图看起来不服从正态分布。
  应查看各组分布以及所选模型的残差。偏离正态性会带来多大影响，取决于各组样本量、
  是否不平衡，以及离群值的严重程度。
- **方差假设随方法而异。** 经典单因素检验与这里支持的平衡双因素检验使用共同误差方差。
  Welch 允许组间方差不等，但仍要求观测独立，其近似 F 参考分布也是在组内误差正态的
  模型下推导的。
- **响应变量与模型应适合研究问题。** Welch 无法解决严重离群值、重复测量或模型不适用
  的问题。缺失数据也需要有依据的处理方案，直接删除观测不能代替假设检查。

这些是统计推断的要求，与函数能否接收某个数组是两回事。函数不会替你诊断独立性、
正态性或离群值。[SciPy 的 ANOVA 说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.f_oneway.html)
总结了经典检验的假设及不等方差时的替代方法。

## 根据设计选择分析方法

| 问题与设计 | 从这里开始 | 使用前注意 |
|---|---|---|
| 按一个因素分组，各组独立且总体方差相等时，均值是否相等？ | [经典单因素 ANOVA](anova-oneway.md)，`f_oneway` | 各组样本量可以不同；仍需独立性与总体等方差假设 |
| 独立组的总体方差不等时，均值是否相等？ | [Welch ANOVA](anova-welch.md)，`f_welch` | 使用各组方差估计，分母自由度通常为小数 |
| 两个交叉因素如何影响结果？一个因素的作用是否取决于另一个因素？ | [平衡双因素 ANOVA](anova-twoway.md)，`f_twoway` | 所有因素组合需要相同样本量；事先判断模型是否需要交互项 |
| 总体方差相等时，具体哪些组均值不同？ | [Tukey HSD](anova-posthoc.md#anova-tukey)，`tukey_hsd` | 全部两两比较共用合并方差；样本量不等时采用 Tukey–Kramer 调整 |
| 不要求等方差时，具体哪些组均值不同？ | [Bonferroni 两两 Welch 检验](anova-posthoc.md#anova-bonferroni)，`bonferroni` | 全部两两检验组成一个比较族；返回的 P 值是原始值 |
| 样本中的分组差异有多大？ | [效应量](#effect-sizes)，`cohens_f`、`partial_eta_squared` | 效应大小与统计显著性回答不同问题 |

选择模型应从研究问题与采样设计出发，不要尝试多个方法后只保留最小的 P 值。
解释结果前，先查看各组样本量、分布与方差差异。后续比较也应沿用合适的设计和方差假设，
不能仅因 Welch 检验显著就改用要求共同方差的 Tukey 比较。

## 从总体检验走向有用结论

需要区分三个问题：**总体检验**判断关于总体均值或因素效应的联合原假设是否与数据相符；
**效应量**描述观测到的差异或变化有多大；**两两比较**则针对指定的两个均值之差。
总体检验的 P 值很小，只回答了第一个问题。

总体检验显著，并不意味着后续可以直接使用未校正的两两检验。挑选结果之前，应先明确
哪些比较属于同一个比较族，并选择合适的多重比较方法。看过 P 值后只挑最可能显著的几对，
不能消除多重比较问题。反过来，预先规划好、并已考虑多重比较校正的两两分析，也不必等
总体检验显著后才进行。[事后比较教程](anova-posthoc.md)解释均值差方向、校正后的判定
与置信区间；[多重检验原理](multiple-testing.md)进一步解释族错误率与错误发现率。

## 效应量究竟衡量什么

在平方和分解模型中，某个效应的普通 eta 平方为

$$\eta^2=\frac{SS_{effect}}{SS_{total}}.$$

它描述总**样本**变异中与该效应有关的比例。经典单因素结果中的 `eta_squared`
以组间平方和为分子；双因素结果则分别报告因素 A、因素 B 和交互作用的普通 eta 平方。
这些数值都不是原假设为假的概率，也不能直接解释成因果作用的比例，或认为已经无误差地
知道了总体中的相应数值。

偏 eta 平方使用不同的分母：

$$\eta_p^2=\frac{SS_{effect}}{SS_{effect}+SS_{error}}.$$

`partial_eta_squared(ss_effect, ss_error)` 计算这个比值。经典单因素设计只有一个效应，
所以偏 eta 平方等于普通 eta 平方；在多因素设计中，它的分母排除了其他效应，
二者通常不同，各项偏 eta 平方之和也不必为 1。报告时应写明采用哪种效应量和哪个模型，
不要把普通与偏 eta 平方混在一起比较。[双因素示例](anova-twoway.md#effect-sizes)
展示了两种分母的区别。

`cohens_f(*groups)` 通过经典单因素计算得到 $f=\sqrt{\eta^2/(1-\eta^2)}$。
Welch 结果中的 `eta_squared` 始终为 `NaN`，因为此接口不提供 Welch 专用效应量。
对同一批数据调用 `cohens_f`，得到的仍是经典 ANOVA 的描述性效应量，
不能将它当作经不等方差调整的 Welch 效应量。这两个辅助函数都不提供效应量的置信区间。

效应量应与响应变量原始单位下的均值和差值一起解读。大样本可能让很小的差异也达到
统计显著；噪声较大、样本较少时，有实际意义的差异也可能仍不确定。
“小效应”“大效应”等经验划分不能代替具体领域的判断。

<a id="reporting"></a>

## 把研究问题、差异大小与不确定性一起报告

1. 说明响应变量及其单位、因素与水平、独立抽样单位、各组或单元格样本量，以及缺失数据
   如何处理。
2. 写明模型、方差假设，以及查看结果前选定的显著性水平。双因素模型应先考察交互作用，
   再解释对另一个因素各水平取平均后的主效应。
3. 报告各组或单元格的均值与离散程度、F 统计量、两项自由度和 P 值。
   结果不显著表示仍有不确定性，不能据此证明均值相等或两组等效。
4. 明确效应量的名称，同时报告原始单位下的差异和合适的不确定性估计。
   进行两两比较时，应说明比较族、校正方法和置信区间的解释方式。
5. 结论应符合研究设计能支持的范围。检验可以描述关联；要作因果解释，还需要相应的
   研究设计与额外假设。

## 支持范围

模块包含**七个公开函数**：三个总体检验函数、两个两两比较函数和两个效应量辅助函数。
这七个函数并不对应七种 ANOVA 设计。[完整 API 参考](../../reference/anova-api.md)
列出全部函数与五种结果类型，包括表示单项比较的 `PairwiseComparison`。

支持的设计是独立组经典单因素 ANOVA、Welch 单因素 ANOVA 和平衡双因素 ANOVA。
`f_twoway` 没有 Type I/II/III 平方和选择参数，单元格样本量不等时会报错。
这些函数不提供重复测量 ANOVA、ANCOVA、MANOVA、任意对比或更多因素的 ANOVA。
设置 `interaction=False` 会拟合加性模型，并将交互变异并入残差，主效应检验也随之改变。

所有基于观测数据的函数都会拒绝 NaN 与无穷输入，而不会静默删除观测值。
即使输入不含 NaN 或无穷值，常数数据仍可能使统计量未定义或变为无穷大。
遇到这类结果时，请查阅各函数的[输入与退化情形说明](../../reference/anova-api.md)。

### 数组、设备与数值限制

各组统计量可以使用 NumPy、CuPy 或 Torch 计算，结果由 Python 标量和比较记录组成。
部分最终的分布计算在 CPU 上执行，其中 Tukey 的学生化极差分布使用 SciPy。
`backend="torch"` 本身不要求 CUDA；双因素数据以嵌套单元格传入时，请显式选择后端。
`dtype=None` 使用所选后端的 float64，统计推断建议保留这一默认精度，
除非已经核对过降低精度对结果的影响。

输入、dtype、数组转换与设备的完整规则见 [API 参考](../../reference/anova-api.md)；
估计器的 `device` 参数采用另一套约定，见[设备指南](../../guides/device-and-memory.md)。
ANOVA 没有供用户选择的严格模式或近似模式。
[经典单因素 GPU 示例](anova-oneway.md#gpu-execution)演示如何显式使用 CuPy 或 Torch CUDA
数组，检验的统计模型不变。
