# 多重检验与 P 值合并

> 语言：中文  
> 最后更新：2026-10-12\
> 切换：[English](../../en/models/multiple-testing.md)

本页解释为什么多次检验需要额外考虑错误率、如何选择方法，以及主要方法的计算思路。
完整的函数签名、返回形状、别名与后端选项见 [API 参考](../guides/multiple-testing-combine-pvalues.md)。

## 为什么每次都用 5% 阈值还不够

假设所有原假设都成立，每次检验恰有 5% 的概率错误地拒绝原假设。
若各次检验**相互独立**，一次都不犯错的概率可以相乘，因此

$$P(\text{至少发生一次错误拒绝})=1-(1-0.05)^m.$$

检验五次时，这个概率约为 22.6%；检验二十次时，约为 64.2%。
原来的 5% 阈值约束的是每次检验，并没有把整组检验的错误风险限制在 5%。
若检验之间存在依赖关系，上面的乘积公式未必成立，但分别使用 5% 阈值，
通常仍不能保证整组检验的族错误率不超过 5%。

多重检验校正考虑了“多次获得假阳性结果”的机会。它不能修复原始检验校准不当、
模型假设无效，或看到 P 值后才将部分已完成的检验排除在校正假设族之外的问题。

## 先分清两个问题

需要对一组假设逐项作出判断时，使用 `adjust_pvalues`；需要把多个检验的证据汇总为一个总体原假设的检验时，使用 `combine_pvalues`。合并后的 P 值显著，并不能确定具体哪些原假设不成立，也不等于控制了逐项发现的 FDR。

例如，“这五个指标中，具体哪些发生了变化？”需要逐项校正后的判断；
“是否有证据表明至少一个指标发生了变化？”则可以通过总体检验回答。
把多个研究针对同一科学原假设的证据合并起来，也是总体检验的用途之一。
校正和合并都不估计效应大小，也不能说明发现的效应是否具有实际意义。

## 先选择要控制的错误率

对于逐项发现，设 $V$ 为错误拒绝的个数，$R$ 为全部拒绝的个数：

$$\mathrm{FWER}=P(V\ge1),\qquad
\mathrm{FDR}=E\left[\frac{V}{\max(R,1)}\right].$$

- **将族错误率 FWER 控制在 5%：** 预先确定的假设族中，出现至少一次错误拒绝的
  概率不超过 5%。当一次错误结论也可能带来较大代价时，这通常是需要考虑的标准。
- **将错误发现率 FDR 控制在 5%：** 在全部拒绝中，错误拒绝所占比例的期望不超过 5%；
  没有拒绝时，该比例定义为零。这里的期望是对重复获取的数据集而言，
  **不保证每次得到的发现列表中错误比例都不超过 5%**，也不是说每个发现都有 5% 的
  概率是错的。如果筛选阶段能够容忍部分假线索，并会进一步验证，FDR 往往更合适。

两种保证都要求单项 P 值有效：在真实原假设下，对 $0\le t\le1$，应有
$P(p_i\le t)\le t$。一个数落在 `[0,1]` 内，并不足以说明它是校准正确的 P 值。
此外，还必须满足所选方法的依赖条件。

- **Holm 或 Bonferroni：** 在任意依赖关系下控制 FWER。Bonferroni 对每项都使用
  `alpha / m` 阈值；Holm 则在较小的 P 值依次通过比较后逐步放宽阈值。
  对同一假设族，Holm 的检验功效不会低于 Bonferroni。
- **BH：** 在相互独立或满足特定正依赖条件时控制 FDR，例如对真实原假设满足 PRDS 条件。
  它按排序位置设置阈值，允许将一组较小的 P 值共同选入发现列表；不能对所有依赖结构保证 FDR 控制。
- **BY：** 通过额外的调和因子，在任意依赖关系下控制 FDR。更广泛的保护通常意味着比 BH 更少的发现。
- **Hochberg：** 在独立或能够保证 Simes 不等式成立的依赖条件下控制 FWER；
  仅知道两两相关系数非负，并不足以普遍保证适用。

应在查看结果前确定假设族和错误率标准，不要先只保留观测到的较小 P 值，再对这个子集进行校正。
对矩阵设置 `axis=1` 时，每行分别构成一个假设族，并不同时控制所有行的总体错误率。
[R 的 p.adjust 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)介绍了这些方法及其依赖条件。

## 可直接运行的 CPU 示例

下面用五个示意性的检验组成一个预先确定的假设族。按顺序运行各段代码，
先导入校正与合并函数。

<!-- api-example: multiple-testing-learner -->
```python
import numpy as np
from statgpu.inference import adjust_pvalues, combine_pvalues
```

一维数组 `p` 的形状为 `(5,)`，每个检验提供一个有效 P 值。
输入顺序对应假设顺序，返回结果也保留这一顺序。

```python
p = np.array([0.001, 0.01, 0.03, 0.05, 0.50])
```

### 用 Holm 逐项作出判断

在预先选定的 5% 水平下控制族错误率。Holm 先将 P 值从小到大排序，
再将第 $i$ 项与 $\alpha/(m-i+1)$ 比较：

| 排序位置 | 排序后的 P 值 | 5% 水平下的 Holm 阈值 | 判断 |
|---|---|---|---|
| 1 | 0.001 | 0.05 / 5 = 0.0100 | 拒绝，继续比较 |
| 2 | 0.010 | 0.05 / 4 = 0.0125 | 拒绝，继续比较 |
| 3 | 0.030 | 0.05 / 3 ≈ 0.0167 | 不拒绝，停止 |
| 4 | 0.050 | 0.05 / 2 = 0.0250 | 已停止，不拒绝 |
| 5 | 0.500 | 0.05 / 1 = 0.0500 | 已停止，不拒绝 |

这是**逐步下降**规则：一旦某一步不通过，后面的原假设都不再拒绝。
接口通过校正 P 值表达同一规则。

```python
reject, adjusted = adjust_pvalues(p, method="holm", alpha=0.05, backend="numpy")
print(reject.tolist())
print(np.round(adjusted, 3))
```

拒绝掩码为 `[True, True, False, False, False]`，校正值为
`[0.005, 0.04, 0.09, 0.1, 0.5]`。按所设定的假设族与错误率，拒绝前两个原假设。
校正 P 值不是重要性排名，未拒绝也不等于证明原假设成立。

### 对照 BH 的 FDR 控制

如果目标是控制 FDR，而且依赖条件适用，BH 将第 $i$ 项与 $i\alpha/m$ 比较。
找到满足 $p_{(k)}\le k\alpha/m$ 的**最大**排序位置 $k$，再拒绝第 1 项到第 $k$ 项。
如果没有任何位置通过，就不拒绝任何原假设。

| 排序位置 | 排序后的 P 值 | 5% 水平下的 BH 阈值 | 比较结果 |
|---|---|---|---|
| 1 | 0.001 | 0.010 | 通过 |
| 2 | 0.010 | 0.020 | 通过 |
| 3 | 0.030 | 0.030 | 通过，且是通过的最大位置 |
| 4 | 0.050 | 0.040 | 不通过 |
| 5 | 0.500 | 0.050 | 不通过 |

```python
reject_bh, adjusted_bh = adjust_pvalues(p, method="bh", alpha=0.05, backend="numpy")
print(reject_bh.tolist())
print(np.round(adjusted_bh, 4))
```

BH 返回 `[True, True, True, False, False]`，校正值为
`[0.005, 0.025, 0.05, 0.0625, 0.5]`。第三项被选中，是因为这里采用了 FDR 标准，
而不是 Holm 所控制的、更严格的 FWER；这并不意味着任何场景都应选择 BH。

BH 是**逐步上升**方法，不能从最小 P 值开始比较，并在首次不通过时停止。
例如，对 `[0.02, 0.03, 0.04]`，取 `m=3`、`alpha=0.05`，
第一次比较不通过（`0.02 > 0.05 / 3`），但最大位置通过（`0.04 <= 0.05`），
因此 BH 会拒绝全部三个原假设。

```python
p_step_up = np.array([0.02, 0.03, 0.04])
reject_step_up, adjusted_step_up = adjust_pvalues(
    p_step_up, method="bh", alpha=0.05, backend="numpy",
)
print(reject_step_up.tolist())  # [True, True, True]
```

### 用 Fisher 回答总体问题

现在复用同一组 `p` 值回答另一个问题：合并证据是否与五个原假设同时成立的
交集原假设不相符？这种解释要求原假设下的 P 值相互独立、连续且服从均匀分布。

```python
statistic, global_p = combine_pvalues(p, method="fisher", backend="numpy")
print(round(float(statistic), 4), round(float(global_p), 6))
```
<!-- example-end: multiple-testing-learner -->

统计量约为 `37.4167`，总体 P 值约为 `0.000048`。在上述假设下，它提供了
反对交集原假设的证据，但不能确定具体哪些分量原假设不成立。

## 校正公式

将 P 值排序为 $p_{(1)}\le\cdots\le p_{(m)}$，令 $c_m=\sum_{j=1}^m1/j$。下列计算完成后，再恢复输入顺序：

$$
\begin{aligned}
\tilde p^{\rm Bonf}_{(i)} &= \min(1,mp_{(i)}),\\
\tilde p^{\rm Holm}_{(i)} &= \min\{1,\max_{j\le i}(m-j+1)p_{(j)}\},\\
\tilde p^{\rm BH}_{(i)} &= \min\{1,\min_{j\ge i}(m/j)p_{(j)}\},\\
\tilde p^{\rm BY}_{(i)} &= \min\{1,c_m\min_{j\ge i}(m/j)p_{(j)}\},\\
\tilde p^{\rm Hochberg}_{(i)} &= \min\{1,\min_{j\ge i}(m-j+1)p_{(j)}\}.
\end{aligned}
$$

返回的拒绝规则是 `adjusted <= alpha`。Holm 的累积最大值保留了停止规则；
BH、BY 和 Hochberg 的反向累积最小值保留了逐步上升的判断。
使用校正 P 值，可以直接套用所选显著性水平，不必自己排序并恢复原顺序。
未拒绝原假设不代表已经证明它成立。

## 合并公式与适用条件

### Fisher：累加对数证据

较小的 P 值会产生较大的正值 $-2\log p_i$。累加这些值，等价于用 P 值的乘积
作为反对总体原假设的证据；它并不是对 P 值取平均。

$$T_F=-2\sum_{i=1}^m\log p_i,\qquad p_{\rm global}=P(\chi^2_{2m}\ge T_F).$$

如果原假设下的 P 值连续且均匀分布，$-2\log p_i$ 服从自由度为 2 的卡方分布。
独立性使这些自由度可以相加，得到上面的 $2m$ 自由度参考分布。
这种精确校准不能直接套用到离散或相关检验。此接口不估计依赖关系的修正。
`weights` 必须为 `None`；提供权重会抛出 `ValueError`。

### Stouffer：累加标准化证据

先将每个 P 值转换为 $z_i=\Phi^{-1}(1-p_i)$，其中 $\Phi$ 是标准正态分布的 CDF。
较小的 P 值对应较大的正分数，大于 0.5 的 P 值则贡献负分数。
对非负且总和为正的权重，

$$T_Z=\frac{\sum_i w_i\Phi^{-1}(1-p_i)}{\sqrt{\sum_iw_i^2}},\qquad p_{\rm global}=1-\Phi(T_Z).$$

当原假设下的 P 值相互独立、连续且服从均匀分布时，转换后的分数是独立标准正态变量，
加权和的方差为 $\sum_iw_i^2$；除以其平方根，就恢复了标准正态参考分布。
若分数相关，方差还包含协方差项；此接口不估计这些项，也没有相应的分母校正。
等权时，统计量简化为 $\sum_i z_i/\sqrt m$。
研究有方向的效应时，应使用方向一致的单侧 P 值；传入双侧 P 值不会自动恢复效应正负号。
[SciPy 的合并检验文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.combine_pvalues.html)说明了独立检验的校准条件。

### Cauchy/ACAT：用重尾变换突出小 P 值

正切变换会使很小的 P 值贡献很大的正值：在零附近，
$\tan\{\pi(1/2-p_i)\}\approx1/(\pi p_i)$。
因此，少数小 P 值就可能贡献大部分证据，不过接近 1 的 P 值也会贡献很大的负值。
实现先将权重归一化为 $a_i=w_i/\sum_jw_j$，未提供时等权，再计算

$$T_C=\sum_i a_i\tan\{\pi(1/2-p_i)\},\qquad p_{\rm global}=1/2-\arctan(T_C)/\pi.$$

若原假设下的 P 值相互独立、连续且服从均匀分布，权重固定、非负且归一化，
则在精确算术下，该统计量服从标准 Cauchy 分布。
存在依赖关系时，Cauchy 尾部是在一定正则条件下的近似。
例如，[Liu–Xie 论文](https://arxiv.org/abs/1808.09011)中的固定维度结果，
使用两两联合正态的原假设统计量所产生的双侧 P 值，讨论的是极限尾部性质；
它不是对任意联合分布、任意显著性水平都成立的精确校准。
它用于汇总证据，不能代替逐项发现的多重检验校正。

### 选择合并方法及权重

确定要检验总体原假设后，应先检查校准条件，再选择统计量。
Fisher 对独立检验提供不带权重的对数证据计算；Stouffer 在独立性假设下，
通过加权正态分数调整各项证据的相对影响。
若有理由采用尾部近似，Cauchy/ACAT 可用于相关检验；它并不是对未知依赖结构的通用修正。

Stouffer 和 Cauchy 使用相对权重：全部权重乘以同一个正常数，数学结果不变。
接口会对两者的权重归一化；这一缩放在 Stouffer 的分子与分母中抵消，
Cauchy 的权重则相加为 1。零权重使该项不再贡献统计量，但对应 P 值仍须是有效输入。
函数不会从数据中学习权重。应预先指定权重，或说明其与原假设检验统计量的独立性，
不要在看到较小 P 值后才增加它们的权重。这里的 Fisher 不支持权重。

合并双侧 P 值不能恢复效应方向，总体 P 值较小也不等于估计出了一个共同效应。
如果科学问题需要效应大小及其不确定性，仅靠 P 值合并还不够。

## 实际使用限制

输入应为 `[0,1]` 内的有限 P 值，`alpha` 应为严格介于 0 和 1 之间的有限数。当前 `alpha=NaN` 不会报错，而会返回全为假的拒绝掩码；若显著性水平由计算得到，应先检查其有效性。无效的 P 值会被拒绝。

合并检验会截断端点概率，分布尾部计算也可能受到浮点相消影响；返回零不代表真实概率精确等于零。[完整 API 指南](../guides/multiple-testing-combine-pvalues.md)说明了签名、别名、权重、轴、后端和数值限制。估计器辅助方法返回字典，与模块函数的元组不同，见[共享估计器方法](../reference/estimator-api.md)。

使用 Cauchy/Stouffer 时，还应在调用前[验证并缩放较大的权重](../guides/multiple-testing-combine-pvalues.md#validate-and-rescale-combination-weights)：即使每个权重都有限，当前归一化求和仍可能溢出，产生错误的有限结果或 NaN。

分析大量相关检验前，应先明确是在检验总体假设还是识别个别发现，并确定依赖条件；“全基因组关联分析”等应用名称本身不能决定应该使用哪一种方法。
